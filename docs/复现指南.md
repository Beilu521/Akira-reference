# 复现指南:把这份参考代码变成你自己的

> 目标不是"看懂",是**合上参考代码后能重建核心链路,并回答每个设计为什么**。
> 预估 6~10 周(每天 2~3 小时);寒假全职 3~4 周。
> 方法:每场小仗三轮——**照着敲 → 填空 → 白板**,每轮"偷看次数"必须下降。

## 零、开始前的心态校准

- 整个项目 3700 行,看起来不可能手写——**没人手写 5000 行,包括写出这份参考代码的过程**,
  它也是分十几轮、每轮几百行长出来的。你打的是 20 场 30 行的小仗,不是一场 5000 行的战役。
- 手写不是背,是**从需求推导**。例:ReAct 循环的四句"为什么"——
  1. 模型要看完整历史 → messages 数组不断追加
  2. 回包要么是答案要么是 tool_calls → 每轮先判断有没有 tool_calls
  3. 工具结果必须回到对话里(否则模型看不到)→ role=tool 消息带 ToolCallID
  4. 模型可能永远调不停 → 循环上限兜底
  这四句话翻译成 Go 就是那 30 行。理解"为什么"的人永远写得出来,背代码的人会忘。

## 二、每场小仗的固定流程

1. **读**:把目标文件读完,合上,写下"这段代码在解决什么问题"(用自己的话,3 句以内)
2. **照着敲**:敲进你自己的项目(Akira),运行 + 过测试
3. **填空**:让 AI/自己把关键 10 行删掉,凭理解补全
4. **白板**:只看需求描述写;卡住了先推导,实在不行偷看一眼——记录偷看次数
5. **对比**:和你抄的版本 diff,每个差异问"哪种更好,为什么"

## 三、面试 20 问(每题都标了出处,答不上就回去重读)

**核心链路**
1. 为什么正则必须预编译?给数字。→ `detector/bench_test.go`(预编译 ~1.4µs vs 逐次编译 ~13.7µs,约 10 倍;50 条规则下分类匹配快 1.6 倍)
2. ReAct 循环里 messages 数组怎么变长?为什么要把 assistant 的 tool_calls 消息也放回去?→ `agent.go`
3. 工具执行失败为什么返回错误文本而不是中断循环?→ `agent.go executeToolCall`(自我纠错)
4. `json.Unmarshal` 的错误为什么不能吞?吞了会发生什么?→ 就是你原项目修过的 bug
5. LLM 返回的 arguments 是对象还是字符串?为什么?→ OpenAI 协议的坑,`llm.Function`
6. 5xx 重试、4xx 为什么不重试?退避怎么算?→ `llm.ChatCtx` + `APIError.Retryable`
7. 流式里 tool_calls 增量怎么拼?为什么发过增量就不再重试?→ `llm.ChatStreamCtx`

**并发与稳定性**
8. watch 模式里有几个 goroutine?各干什么?画出来。→ `main.go runWatch`
9. 分析 worker 为什么串行?并发池不是更快吗?→ 成本中心是 LLM,不是速度
10. 分析队列满了怎么办?为什么不能阻塞检测循环?→ `select + default` 背压
11. Aggregator 的 Close 时序契约是什么?违反了会怎样?→ panic:发向已关闭 channel
12. Ctrl+C 之后发生了什么?按顺序说。→ signal → ctx → watcher 收尾 → 聚合冲窗 → 关管道 → worker 收尾

**采集与存储**
13. watcher 怎么处理文件轮转和 truncate?offset 状态机的三个分支?→ `watcher.go`
14. 半行缓冲(pending)解决什么问题?→ 日志写到一半没有换行符
15. SQLite 换 PostgreSQL 要改哪些代码?为什么?→ Store 接口,换实现不改调用方

**告警与评测**
16. 聚合和冷却去重有什么区别?各自适用什么场景?→ 聚合保信息,冷却更简单
17. 精确率和召回率哪个更重要?告警场景呢?→ 误报疲劳 vs 漏报事故,答"看业务"并给方案
18. 你的评测数字是多少?哪些误报?怎么修?→ 89.7%/100%,OOMScore 陷阱 + 503.js URL 缺陷
19. 相似历史检索为什么用 TF-IDF 不用向量库?什么时候该换?→ 规模取舍
20. 日志量涨 100 倍怎么办?→ `docs/架构演进.md`,接口留缝 + LLM 是成本中心

## 四、复现时最容易踩的坑(前人经验)

- 别跳过测试写功能:测试是"这个功能到底什么行为"的可执行规格说明
- 别一次性写完再跑:每 30 行就 build + test 一次
- config 里字段加了没人用 → 先写"谁消费它",再写结构体
- 中文截断按字节切 → 乱码;按 rune → `[]rune(s)[:2000]`
- 时间比较用 `Equal` 不要用 `==`(monotonic clock 陷阱)
